# Alex Burguer

Landing page de uma hamburgueria de rua fictícia. Projeto para estudo.

## Como rodar

Os scripts são módulos ES, então o navegador não os carrega abrindo o `index.html` com duplo clique (`file://`).
Sirva a pasta por HTTP, por exemplo:

```
python -m http.server 8000
```

e abra http://localhost:8000. (No VS Code, a extensão Live Server também serve.)

## Testes

```
node --test
```

Testa a lógica de aberto/fechado em `js/horario.js` (fuso America/Sao_Paulo). Não há dependências para instalar.
